СайтКонструктор 1.0 — визуальный конструктор сайтов с ИИ (Windows 10/11, x64)

КАК ПОЛЬЗОВАТЬСЯ
1. «📄 Новый» — выберите шаблон (лендинг, сайт компании, портфолио, кафе, стартап, витрина магазина, блог).
2. Перетаскивайте готовые блоки слева на страницу. Двойной щелчок по тексту — правка, щелчок по картинке → «Заменить картинку».
3. «🎨 Тема» — палитра и шрифты в один клик, тёмная тема, анимации.
4. «🤖 ИИ» — опишите сайт словами («Сделать страницу») или попросите изменить выделенный блок.
   Модели: веб-чаты DeepSeek, GigaChat, Qwen, Claude, Grok (войдите один раз в «Окне чата») или API-ключи GigaChat/DeepSeek/YandexGPT/OpenAI-совместимого (ИИ → Настройки).
   Правки ИИ проверяются (схема, существующие элементы, безопасный HTML/CSS), выдуманные телефоны/цены/e-mail заменяются на [телефон], [цена]…
   Каждую правку можно откатить во вкладке «История». Обычные правки — Ctrl+Z.
   В «Настройках ИИ» впишите настоящие данные о себе — ИИ будет использовать только их.
5. «🔎 SEO» — заголовок, описание, адрес сайта (для sitemap.xml), favicon, коды счётчиков.
6. «⬇ Экспорт» → «В папку»: получится обычная папка (index.html, страницы, css, js, assets) — загрузите её содержимое на любой хостинг. Есть ZIP и загрузка по FTP.
Проект сохраняется в файл .sitebuilder.json (Ctrl+S), плюс автосохранение.

Нужен Microsoft Edge WebView2 Runtime (в Windows 11 уже есть; установщик поставит его сам при необходимости).
